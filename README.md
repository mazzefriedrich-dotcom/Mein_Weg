# Mein Wegbegleiter – Heiterkeit fürs Wohlsein

Eine kleine, freundliche Helfer-App (PWA) für den Alltag mit Handy, Tablet, Alexa und Fernseher.

- Alle Eingaben bleiben **nur auf dem Gerät**. Die App schickt von selbst nichts weg.
- Es werden **keine Passwörter oder PINs** gespeichert.
- Neue Versionen werden **nur nach Zustimmung** übernommen („Was ist neu?“).

Öffnen: über GitHub Pages dieses Repositorys, dann im Browser „Zum Startbildschirm hinzufügen“.
